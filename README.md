# Game Manual Reader

A browser-based reader for FIRST Robotics Competition game manuals. Upload any manual PDF (or use the bundled 2026 REBUILT manual) and read it with a bookmark sidebar, page navigation, zoom and selectable text. Uploaded files stay in the browser and are never sent to a server.

## Develop

```bash
npm install
npm run dev
```

## Deploy

It's a static Vite site, so it deploys to Vercel with no configuration (build command `npm run build`, output `dist`).
